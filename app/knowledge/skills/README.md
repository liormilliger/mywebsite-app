# Skill files

One file per area. The /ask agent loads every `*.md` file in this folder (except this README) into
its knowledge, next to `profile.json`. Everything here is PUBLIC: visitors can see it quoted.

Rules for editing:
- Describe what Lior did and how, in general terms. Don't name his current employer (say "current role"). No client or product names, hostnames, IPs,
  account IDs, ticket numbers, code, credentials or domain-specific details from private work.
- Every claim needs evidence (where it was done, what it achieved). No unbacked superlatives.
- Keep each file under ~450 words so the prompt stays small and cheap.
