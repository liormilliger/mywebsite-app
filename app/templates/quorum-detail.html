Quorum

A collaborative GenAI workspace where teams work with Claude together in shared sessions, combining a streaming AI assistant with a Slack-style team chat. Participants share a Main channel where Claude's streamed answers are visible to everyone, a team chat Claude reads for context, and a private one-on-one channel with Claude per person. Features role-based access via AWS Cognito, shared connectors to MCP servers and Confluence, and living documents that Claude edits in real time with versioned red/green diffs and undo. Built end to end — architecture, backend, frontend, AWS infrastructure as code, and test suites. The source code is in a private GitHub repository.
